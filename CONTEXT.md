# Glen Ridge HOA Website

The public website of the Glen Ridge Homeowners Association (Clearcreek Township, Ohio): where homeowners find news, meetings, governing documents, and the rules for their part of the neighborhood.

## Language

### The neighborhood

**Section**:
One of the 8 platted parts of Glen Ridge, each with its own rules. Every home belongs to exactly one.
_Avoid_: Phase, area, zone; never use "section" for a part of a web page

**Document**:
A titled link to association material that is hosted elsewhere. The site lists Documents; it does not store them.
_Avoid_: File, PDF, upload, attachment

**Portal**:
The management company's homeowner website, where homeowners pay dues and submit requests. It is a separate system the site only links to.
_Avoid_: Payment portal, request portal, account, login

### The site

**Content**:
Anything a board member can change without touching a page: news, meetings, Documents, Sections, site-wide settings.
_Avoid_: Dynamic content, data, CMS

**Shell**:
Everything on a page that is not Content: header, footer, layout, headings that never change.
_Avoid_: Template, chrome, frame

**Band**:
A full-width horizontal region of a page.
_Avoid_: Section, block, row, panel

**Jump**:
Any navigation that moves the viewport within the page the visitor is already on.
_Avoid_: Hop, anchor scroll, in-page link

**Disclosure**:
Content that expands or collapses in place without the visitor leaving the page.
_Avoid_: Accordion, dropdown, toggle, reveal
